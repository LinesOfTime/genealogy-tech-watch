# Проверка перед публикацией

Дата: 2026-10-22. Ветка: main. До подготовки локального коммита выполнен git fetch;
origin/main и HEAD совпадали (0 входящих / 0 исходящих коммитов).
Это не разрешение push: публикация требует отдельного явного решения пользователя.

## Состав изменений

Рассмотрены этапы A–E: аудит, read-only валидатор, журнал кандидатов, сравнение и
ручное утверждение, dry-run/apply, синхронизация статических данных и интерфейс.
Сохранены подробные исследования и исходные оценки; «Для России» извлечено с
указанием исходной строки, без повышения доказательности. Браузерные импорты не
подменяют опубликованные данные.

Одна подтверждённая находка htrflow-batch применена по решению пользователя.
Сохранены 164 проекта и 142 исследования; дайджест: 19 событий / 5 выпусков.
Не переписывались старые лицензии, приоритеты, описания и путеводитель. Отдельно
сохранены заявления авторов и отсутствие независимого испытания HTR.

Перед публикацией дополнительно устранён пробел валидатора: новое событие
проверяется по обязательным метаданным и сверяется между history, watch_events,
дайджестом, журналом и реестром хешей. Потеря утверждения, источника, даты,
применённой записи или журнала блокирует validate. При --input утверждённая запись
сохраняется в основной журнал; конфликт содержимого требует согласования.
Некорректный URL не должен приводить к необработанному исключению валидатора.

README обновлён под фактические команды; добавлены адресный список файлов и проверка
подготовленного коммита. Этап F — внешнее расписание — не включён.

## Проверки

- 42 unit-теста (35 прежних, 4 проверки целостности события, 3 проверки состава
  публикации). Среди них сохранность, конфликты, пустой/повторный результат,
  устаревшее утверждение, откат ошибки записи, извлечение существующих оценок.
- JavaScript smoke на фактических данных: 164 карточки, фильтры по источникам
  оценок, 19 событий/ссылок, полные исследования, отсутствие подмены localStorage,
  однократное отображение события и раздельные факты/заявления авторов.
- Валидатор: 0 ошибок, 308 исторических предупреждений, не замаскированных
  автоматическими исправлениями. JSON-копии и seed согласованы.
- Повторный apply: files: [], одна запись пропущена как уже применённая.
- git diff --cached --check. Проверка известных форматов токенов/приватных ключей,
  отсутствия workflows, бинарных данных и файлов больше 5 MiB в Git-снимке.
  Проверка секретов ограничена известными шаблонами, не является полным аудитом.
- tools/check_publication.py материализует именно индекс Git в одноразовой папке
  и запускает валидатор, unit-тесты и JS smoke из подготовленного снимка.

Результаты исполняемых проверок должны быть успешны до создания коммита.
Содержимое исследований после первоисточниковой проверки не менялось на этом шаге.
Список новых/изменённых файлов: data/publication-files.json (42 адресных пути).
Сторонние резервные копии, вспомогательные скрипты, Python-кэш и local-apply.diff
в этот список не включены. Предшествующий компактный дизайн docs/index.html
сохранён в составе интерфейса.

## Локальная проверка

```powershell
Set-Location D:\AI\genealogy-tech-watch-git
python tools/watch_pipeline.py validate
python -m unittest discover -s tests -v
node tests/ui_smoke.cjs
python tools/watch_pipeline.py apply --approved-only --edition-date 2026-10-22 --dry-run
git diff --check
```

Для адресной подготовки индекса после просмотра manifest (не git add .):

```powershell
$publicationFiles = Get-Content -LiteralPath data/publication-files.json -Raw | ConvertFrom-Json
git add -- $publicationFiles
python tools/check_publication.py
git diff --cached --stat
```

Локальный коммит создаётся после проверки индекса. Перед последующим push нужно
повторить fetch, убедиться, что origin/main не изменился, и получить явное разрешение
публикации. При изменении удалённой ветки сначала согласовать изменения и повторить
проверки; не использовать force-push. GitHub Pages остаётся main / docs, без Actions.
