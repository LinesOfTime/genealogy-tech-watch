# Genealogy Tech Watch — Линии времени

**Исследовательский каталог открытых инструментов цифровой генеалогии, архивных технологий и ИИ** с датированным дайджестом изменений. Он помогает выбрать решения для исследования источников, обработки исторических документов и разработки генеалогических систем.

**[Открыть каталог](https://linesoftime.github.io/genealogy-tech-watch/) · [OCR/HTR: межпроектные решения (11.11)](https://linesoftime.github.io/genealogy-tech-watch/ocr-htr-coordination-2026-11-11.html)** · [Дайджест](https://linesoftime.github.io/genealogy-tech-watch/digest.html) · [Подобрать по задаче](https://linesoftime.github.io/genealogy-tech-watch/tasks.html) · [Лицензии](https://linesoftime.github.io/genealogy-tech-watch/licenses.html) · [Приоритеты](https://linesoftime.github.io/genealogy-tech-watch/priorities.html)

## Что можно найти

- Генеалогические программы, GEDCOM, семейные деревья, источники и доказательства.
- OCR/HTR, индексация рукописных документов, цифровые архивы и IIIF.
- Исторические места, приходы, административно-территориальные изменения и геоданные.
- Сопоставление персон и записей, исследовательские рабочие места, AI-агенты, API/MCP.
- Инструменты смежных областей: digital humanities, knowledge graphs, GLAM и исторические исследования.

Каталог поддерживает поиск, фильтры по направлению, редакционному приоритету и применимости для России, карточки с ограничениями и лицензиями, расширенные исследования и подбор по задаче. Статические страницы содержат встроенные данные для автономного просмотра; отдельные подробные материалы и внешние ссылки могут требовать сеть.

## Состояние данных и ограничения

**Снимок по объединённому [PR #2](https://github.com/LinesOfTime/genealogy-tech-watch/pull/2), 24 октября 2026:** 169 карточек, 149 расширенных исследований, 30 событий в 7 выпусках. Эти числа — состояние конкретного обновления, а не автоматически обновляемый счётчик README; текущие значения отображаются на сайте и в опубликованных JSON.

Каталог объединяет ранее подготовленные исследования и новые проверенные события. **Дата выпуска не означает повторную проверку всех репозиториев.** Для исторических карточек полнота и актуальность сведений различаются. Существование проекта, сведения из README, заявления авторов, статическая проверка исходников и независимое испытание — разные уровни доказательности.

«Применимость для России» — редакционная оценка по назначению и материалам проекта; она **не подтверждает** доступность сервиса из РФ, качество распознавания русских рукописей или поддержку исторической административной географии. В каталоге есть **две независимые шкалы**: редакционная P1–P3 (интерес для развития платформы) и практическая P1–P3 (готовность к небольшой пробе под задачу). Они не являются рейтингом качества или популярности, и разные значения у одного проекта не означают ошибку. Независимые испытания отслеживаются отдельно. Неизвестные лицензии и характеристики не следует считать подтверждёнными.

**Последняя выборочная проверка первоисточников:** [9 ноября 2026 — четыре проекта из очереди](data/review-queue-2026-11-09.md). Это не пересмотр всего каталога.

## Как обновляется каталог

1. Исследователь или ChatGPT проверяет новые проекты и релизы, сравнивает с существующим каталогом и фиксирует источники, ограничения и степень подтверждения.
2. Пакет `watch-package.json` размещается в ветке `watch-inbox/*`. Публикация пакета в такой ветке настроена как триггер GitHub Actions **Watch Updater**.
3. Workflow формирует предварительный план, проверяет структуру, снимки первоисточников, хеши, дубликаты и возможность применения. При успешной проверке автоматический режим пытается применить пакет и отправить изменения в `main` с использованием секрета окружения `watch-publish`.
4. Публикация GitHub Pages настроена из `main:/docs`. Отдельный ручной режим `preview` / `publish` сохранён для диагностики и контролируемых обновлений.

**Важно:** наличие автоматического триггера в репозитории не доказывает успешность конкретного запуска. Проверяйте результат в [Watch Updater Actions](https://github.com/LinesOfTime/genealogy-tech-watch/actions/workflows/watch-updater.yml), коммит публикации в `main` и карточки на сайте. Сведения о сторонних проектах и их возможностях не становятся независимо подтверждёнными только вследствие прохождения технических проверок. Автоматический режим публикует прошедшие проверки события без отдельного редакционного подтверждения; используйте его только для заранее проверенных пакетов.

Подробности: [Watch Updater](UPDATER.md), [процедура находок](DISCOVERY_WORKFLOW.md), [безопасное применение](APPLY_WORKFLOW.md), [интерфейс](INTERFACE_REVIEW.md), [отчёт обновления 24 октября](docs/WATCH_REVIEW_2026-10-24.md).

## Локальный запуск

Нужен Python со стандартной библиотекой; для UI smoke-тестов — Node.js. Команды ниже не устанавливают зависимости и не выполняют push:

```powershell
Set-Location D:\AI\genealogy-tech-watch-git
python tools/watch_pipeline.py validate
python -m unittest discover -s tests -v
node tests/ui_smoke.cjs
python -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8000/docs/index.html`.

Для нового выпуска (после проверки и утверждения конкретных событий):

```powershell
python tools/watch_pipeline.py scan --dry-run
python tools/watch_pipeline.py review --report
python tools/watch_pipeline.py apply --approved-only --edition-date YYYY-MM-DD --dry-run
# После проверки плана и его фактического plan_hash:
python tools/watch_pipeline.py apply --approved-only --edition-date YYYY-MM-DD --write --expect-plan HASH
python tools/watch_pipeline.py validate
```

`YYYY-MM-DD` и `HASH` — заполняемые значения, а не буквальные аргументы. Ручные изменения JSON синхронизируются командой `python tools/sync_data.py`. Не обходите проверку хеша и не проставляйте утверждение без решения по конкретному пакету.

## Публикация и ограничения инфраструктуры

Сайт размещается через GitHub Pages из `main` / `docs`. В репозитории используется GitHub Actions workflow `Watch Updater` (`.github/workflows/watch-updater.yml`). Для просмотра предварительных изменений он сохраняет Actions artifact `watch-preview`; автоматический режим при успешных проверках пытается отправить обновления в `main`. Это расходует лимиты GitHub Actions и требует настроенного секрета `WATCH_PUBLISH_TOKEN`.

Внешний мониторинг GitHub и уведомления о находках не запускаются локальными командами `watch_pipeline.py`. Отдельную автоматизацию мониторинга не следует считать включённой без подтверждения её расписания и работы.

**Лицензии сторонних проектов принадлежат их правообладателям.** Перед повторным использованием кода проверяйте лицензию конкретной версии и совместимость условий.

Практическая переоценка от 4 ноября 2026 применяется в поле `practical_priority`; прежнее `priority` сохранено для происхождения исторической шкалы. На сайте и в фильтрах используется практическое значение. Основания, география и ограниченная проба доступны в карточке и на странице приоритетов; тесты каталога не являются независимыми испытаниями перечисленных проектов.
