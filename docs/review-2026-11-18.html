Каталог · Дайджест

GitHub Watch — 18 ноября 2026

Четыре изменения, потенциально значимых для генеалогического исследовательского кабинета.

Уровень проверки: ссылки на первичные коммиты приведены для воспроизводимой проверки. Описание изменений является исследовательской оценкой, не результатом запуска или независимого benchmark. Указанные лицензии нуждаются в сверке с LICENSE соответствующей ревизии. Это отдельный обзор, не подтверждение включения проектов в каталог.

1. AI-Riksarkivet/workbench

Изменение для проверки: Версионирование аннотаций и возобновляемые конвейеры обработки.

Компоненты: Research Workspace; OCR/HTR; provenance/evidence.

Действие: Изучить хранение черновиков, журнал изменений и идемпотентность задач.

Лицензия: Apache-2.0 — требует перепроверки.

Исходный коммит на GitHub

2. gramps-project/gramps-web

Изменение для проверки: Подтверждение предлагаемых ИИ изменений в пользовательском интерфейсе.

Компоненты: Research Workspace; Person Resolver; API/MCP.

Действие: Испытать цикл предложение → проверка → применение на тестовом дереве.

Лицензия: AGPL-3.0 — учитывать при использовании кода.

Исходный коммит на GitHub

3. nbadino/tabularium

Изменение для проверки: Оценка дообученной OCR-модели на эталонном наборе.

Компоненты: OCR/HTR; Indexer.

Действие: Воспроизвести CER и структурные метрики на ревизских сказках.

Лицензия: MIT — требует перепроверки.

Исходный коммит на GitHub

4. rodoslovje/genealogical-index

Изменение для проверки: Ранжирование поиска персон и MCP-доступ к карточкам.

Компоненты: Person Resolver; Indexer; API/MCP.

Действие: Проверить ранжирование, same_as и неполные даты на российских источниках.

Лицензия: MIT — требует перепроверки.

Исходный коммит на GitHub
