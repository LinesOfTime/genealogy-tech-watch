GitHub Watch — 18 ноября 2026

Три новые карточки и обновление Gramps Web.

Проверены исходные коммиты, README и LICENSE соответствующих ревизий. Карточки содержат условия применения и следующий шаг для пилота.

1. AI-Riksarkivet/workbench

Изменение: Черновики аннотаций в PostgreSQL, проверка ревизии задачи при сохранении, ограниченная история и запись итоговых аннотаций в Lance при публикации.

Компоненты: Research Workspace; OCR/HTR; provenance/evidence.

Действие: Изучить хранение черновиков, журнал изменений и идемпотентность задач.

Лицензия: Apache-2.0.

Исходный коммит на GitHub · Карточка исследования

2. gramps-project/gramps-web

Изменение: Подтверждение предлагаемых ИИ изменений в пользовательском интерфейсе.

Компоненты: Research Workspace; Person Resolver; API/MCP.

Действие: Испытать цикл предложение → проверка → применение на тестовом дереве.

Лицензия: AGPL-3.0 — учитывать при использовании кода.

Исходный коммит на GitHub · Карточка исследования

3. nbadino/tabularium

Изменение: Оценка дообученной OCR-модели на эталонном наборе.

Компоненты: OCR/HTR; Indexer.

Действие: Воспроизвести CER и структурные метрики на ревизских сказках.

Лицензия: MIT.

Исходный коммит на GitHub · Карточка исследования

4. rodoslovje/genealogical-index

Изменение: Ранжирование поиска персон и MCP-доступ к карточкам.

Компоненты: Person Resolver; Indexer; API/MCP.

Действие: Проверить ранжирование, same_as и неполные даты на российских источниках.

Лицензия: MIT.
