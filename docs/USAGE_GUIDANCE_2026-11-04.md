## Что видит посетитель

- В каталоге у семи специализированных записей указана география источников.
- В исследовании показаны пример применения, границы покрытия и раскрываемое
  основание: исходный текст, файл, ключ и поле сохранённого описания.
- В подборе по задачам показан сценарий; длинное обоснование доступно в details.
  Поиск понимает названия стран из новых меток: например, «Швеция» и «Швейцария»,
  даже если прежнее описание использовало только прилагательное.
- География видна также при сравнении проектов.
- Вместо одной общей рекомендации для всех 213 соответствий используются семь
  различных проб по задачам: OCR, сканы, дубли, места, исследование, GEDCOM, агенты.
  Это советы по проверке, а не утверждение о поддержке операции каждым кандидатом.

## Сохранение и проверка

`data/usage-guidance.json` хранит редакционные подсказки и точные выдержки из
`catalog.json` / `docs/research.json`. Генератор проверяет существование записи,
допустимое описательное поле и сохранность выдержки. Исходный текст сохраняется
в производных данных. Смена этого текста требует пересмотра подсказки.

`python tools/build_task_matches.py --write` согласованно готовит:
`docs/task-matches.json`, `docs/usage-context.json`, отдельный `usage-seed` каталога.
Генератор использует существующий механизм записи с проверкой исходных байтов
и откатом при обычной ошибке. Основной catalog seed синхронизируется прежним
`tools/sync_data.py`. Повторная генерация не должна менять файлы.

Валидатор блокирует расхождения между исходными подсказками, их JSON и HTML seed;
тесты проверяют производный подбор. Автоматическая проверка происхождения не
заменяет редакционный просмотр смысла стран и сценариев.

Локально: 91 unit test — OK; валидация — 0 ошибок и 173 прежних предупреждения;
UI smoke — OK. Браузерный прогон проверяет поиск по «Швейцария», «Швеция», «Япония»,
переходы к исследованиям, границы покрытия, географию сравнения, неопределённость
универсального MCP, прежние фильтры и мобильную навигацию.

До объединения и проверки GitHub Pages эти изменения не считаются опубликованными.
GitHub Actions не добавляются и вручную не запускаются.
