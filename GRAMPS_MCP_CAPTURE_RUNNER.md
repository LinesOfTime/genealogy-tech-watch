# Исполняемый комплект G-MCP-01

Скрипт `tools/gramps_pilot_report.py` **не вызывает MCP и не проводит испытания**. Он проверяет результаты, записанные оператором после реальных вызовов, наличие файлов подтверждения и контрольные хэши выгрузок дерева.

## Проверенная конфигурация по upstream

По README GitHub-зеркала `Genealogy-MCP/gramps-mcp` (9 ноября 2026): MCP имеет два инструмента `search` и `execute`, операции чтения `get`, `search`, `search_text`, `get_tree_stats` и другие. В `pyproject.toml` указана версия 3.15.27. Upstream — GitLab, поэтому перед экспериментом зафиксируйте actual Git SHA и проверьте, не изменился ли origin. Gramps Web API 3.x обязателен. Сервер MCP сам по себе не выполняет аутентификацию; Docker Compose публикует порт на 127.0.0.1.

Не следует использовать `latest` для воспроизводимого эксперимента. Запускайте фиксированный образ/коммит, изолированное синтетическое дерево и ограниченную учётную запись, используя [план](PILOT_GRAMPS_MCP_01.md).

## Сбор наблюдений

Создайте папку `captures/gramps-mcp-01/` с ответами `T1.json` … `T7.json` (фактические, обезличенные ответы). Создайте `capture.json` со следующими обязательными полями:

```json
{
  "project":"genealogy-mcp/gramps-mcp",
  "project_version":"ЗАПОЛНИТЬ_ПО_ЗАПУЩЕННОЙ_ВЕРСИИ",
  "project_commit":"ЗАПОЛНИТЬ_SHA",
  "gramps_web_version":"ЗАПОЛНИТЬ",
  "api_version":"ЗАПОЛНИТЬ",
  "environment":"ЗАПОЛНИТЬ_ОС_ОБРАЗЫ_КОНФИГУРАЦИЮ",
  "fixture_sha256":"ЗАПОЛНИТЬ_SHA256",
  "before_sha256":"ЗАПОЛНИТЬ_SHA256",
  "after_sha256":"ЗАПОЛНИТЬ_SHA256",
  "executed_at_utc":"ЗАПОЛНИТЬ_UTC_ISO8601",
  "cases":[]
}
```

В `cases` должны быть ровно семь записей с ID T1–T7. Каждая запись имеет `observed` (наблюдение), `expected` (эталон), `notes` (контекст), `passed` (фактически установленное true/false) и `evidence_file` (относительный путь к сырому ответу). Пустые значения, отсутствие подтверждений и неверные хэши отвергаются.

Запуск из корня репозитория:

```bash
python tools/gramps_pilot_report.py captures/gramps-mcp-01/capture.json --output captures/gramps-mcp-01/report.json
python -m unittest discover -s tests -p test_gramps_pilot_report.py
```

Код возврата: 0 — структурно корректны семь наблюдений, оператор отметил их успешными и хэши до/после совпадают; 2 — есть неудачи/изменения; ошибки входных данных — отказ. **Это не независимая проверка правдивости наблюдений.** Не записывать итог в `docs/trials.json` без отдельной рецензии протокола. Не публиковать секреты, cookies или данные живущих лиц.
