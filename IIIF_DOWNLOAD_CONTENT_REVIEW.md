# Уточнение загрузчиков IIIF — 22 октября 2026

По свежей проверке README дополнены две карточки:

- https://github.com/ryanfb/iiif-dl — входной манифест или отдельный идентификатор, Ruby/Bundler/ImageMagick; явное предупреждение авторов о несовместимости с IIIF 3.0.
