# Практическая переоценка: первый пакет — 4 ноября 2026

Проверка ссылок охватывает все 184 карточки: 180 репозиториев ответили на запрос списка коммитов, три адреса вернули 404 (повторно проверен endpoint репозитория), одна запись ведёт на профиль владельца. 404 означает недоступность публичного адреса, а не доказанное удаление. Отсутствие README.md не считается отсутствием репозитория: проверены и альтернативные имена README.

Содержательная переоценка завершена для 20 проектов; ещё 160 существующих репозиториев требуют чтения условий и индивидуального обоснования. Снимки README собраны для дальнейшей работы; сбор снимка не означает завершённой оценки. Для w3c/prov корневой README не найден, это спецификация с собственной структурой.

Все 20 новых оценок — редакционные предложения E1: README и текст лицензии привязаны к одному commit SHA. Код проектов и независимые испытания здесь не проверялись. Прежние P, A/B/C и объекты evaluation сохранены полностью. В каталоге приоритеты не перезаписаны. Страница приоритетов показывает предложения отдельно.

Географическая специализация не понижает приоритет: P1 у ra-mcp относится к Riksarkivet, IWAC — к своей коллекции, eperiodica — к отдельной статье. Массовая выгрузка eperiodica имеет другие предпосылки (proxy). Стандарт оценивается через проверку совместимости, библиотека — через малую интеграцию.
