# Проверка качества оценок и план испытаний — 28 октября 2026

## Что фактически подтверждено

В каталоге 175 проектов, у всех есть поле `evaluation`. Уровни подтверждения: E0 — 144, E1 — 25, E2 — 6. Приоритеты: P3 — 3, P2 — 89, P1 — 72, Не оценён — 11. **Ни один уровень E3/E4 не зафиксирован.** Наличие структурированной оценки не равно проверке репозитория или успешному испытанию.

- E0: карточка прошла только каталожный триаж; upstream не проверен.
- E1: прочитан README, но исходный код, релизы, лицензии, зависимости и заявленные показатели не подтверждены полностью.
- E2: редакционная отметка проверки документации/кода; по каждой такой карточке необходима ссылка на конкретную проверенную версию и фактический набор файлов. Без этого E2 следует считать требующим подтверждения.
- E3/E4: необходим воспроизводимый отчёт с корпусом, окружением, измерениями и ошибками.

## Технический контроль

Добавлен валидатор, который запрещает присваивать числовые оценки E0-триажу, требует отчёт для E3/E4, проверяет диапазоны шкал и значения статусов. Добавлены модульные тесты. До слияния выполнить `python tools/watch_pipeline.py validate` и `python -m unittest discover -s tests -v`. Этот PR не утверждает, что команды уже выполнены.

## Единый сравнительный пилот для генеалогического кабинета

**Корпус:** 30–50 страниц российских исторических документов из законно доступных источников, с фиксированными правами на хранение и обработку. Состав: рукописные метрические книги, печатные документы, смешанные кириллические/латинские записи, таблицы, страницы с дефектами. Для оценки выделить независимые обучающую и тестовую части; эталонные транскрипции и поля подготовить вручную.

| Контур | Кандидаты | Метрики и критерий приёмки |
|---|---|---|
| OCR/HTR | HTRflow, NAFRec, eScriptorium/Kraken, текущий baseline | CER/WER отдельно по типу письма; качество границ строк, доля пропусков, время/страница, RAM/VRAM, доля исправлений человеком |
| Индексация | Chronos, текущий индексатор и простая OCR→LLM цепочка | точность извлечения имени, даты, места, родства; полнота; связь с координатами на странице; доля выдуманных полей |
| Person Resolver | Splink, Dedupe, RecordLinkage, HLink | precision/recall/F1 по размеченным парам; false merge rate отдельно; объяснимость совпадений и устойчивость к вариантам написания |
| Place Resolver/АТД | World Historical Gazetteer, Linked Places, OpenRefine, Allmaps | доля корректных исторических соответствий; учёт административных изменений во времени; число ручных исправлений |
| Доказательства и агенты | Gramps Evidence MCP, ex-USSR Kinship Research, GEDCOM 7, кабинет | каждый вывод связан с источником/страницей; запрет записи без подтверждения; воспроизводимость импорта/экспорта |

**Стоп-условия:** отсутствие прав на обработку документов; неясные лицензии весов; запись агента в основное дерево без согласования; утечка персональных данных; отсутствие ссылок на происхождение утверждений. Не считать авторские benchmark результатами пилота.

## Что должно быть итогом

По каждому контуру: одна сравнительная таблица с версией и лицензией, baseline, метриками, аппаратной средой, логами, ссылками на тестовый корпус и решением **интегрировать / использовать как референс / наблюдать / исключить**. Предпочтение минимальному рабочему адаптеру, а не новому многомесячному проекту.
