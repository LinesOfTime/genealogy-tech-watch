# Подбор и сравнение проектов — 25 октября 2026

Изменения интерфейса по ранее выполненной оценке ui-ux-pro-max:

При смене фильтров выбор сохраняется в открытой странице; сохранение выбора после её закрытия не обещается. Есть удаление, очистка, сообщения о лимите, aria-pressed и клавиатурное управление.
