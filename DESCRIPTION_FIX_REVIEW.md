# Исправление описаний назначения — 2026-10-22

Область: только 47 записей, где catalog.description содержал «Не установлен».
Повторное исследование 164 проектов не проводилось, сетевые источники не читались.

## Результат

- 42 описания восстановлены из существующей строки «Назначение:» guide_excerpt.
- editorial_summary проверялся первым, но у всех 47 записей он пуст.
- 5 остались неопределёнными: linesoftime/yarchive-downloader, mittagessen/kraken,
  nikazzio/scriptoria, omeka/omeka-s, tropy/tropy. У первой нет строки назначения,
  у остальных она сама содержит «Не установлен».
- В 17 восстановленных описаниях сохранены неопределённые формулировки (кандидат,
  возможный, может, потенциально, вероятный). Все 47 записей требуют дальнейшей
  проверки первоисточников; восстановление текста не подтверждает его содержание.

Каждое восстановленное описание начинается с «По редакционным материалам
(без независимой проверки):». Затем дословно идёт выбранный текст; условия и
оговорки не удаляются, текст не сокращается до первого предложения.
Старое значение и происхождение сохранены в description_provenance:
original_description, source (file/key/field/original_text/sha256), interpretation,
evidence_status, uncertainty_markers, additional_verification_required, migration.
SHA-256 относится ко всему исходному полю, а не только извлечённой строке.

Тип проекта и назначение разделены и в интерфейсе подробной карточки:
project_type отображается как «Тип проекта», описание — как «Назначение».
Тип не восстанавливается по назначению; исходный research project_type не меняется.
На странице также видны прежнее описание, ссылка на поле происхождения и исходный
текст. Версия project-ui.js обновлена для обхода прежнего браузерного кэша.

## Отчёт по всем 47

- reports/description-restoration.md: отдельный раздел для каждой записи с
  прежним/новым описанием, полем-источником, результатом и вопросами проверки.
- reports/description-restoration.json: тот же результат в машинном формате,
  включая сохранённые маркеры неопределённости и ограничения путеводителя.

restored_editorial означает восстановление редакционного текста; restored_provisional
дополнительно выделяет явно гипотетическую формулировку; unresolved — нет допустимого
текста. Ни одна из этих категорий не означает независимой проверки назначения.
