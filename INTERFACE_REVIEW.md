## Воспроизведение PowerShell

```powershell
Set-Location D:\AI\genealogy-tech-watch-git
python tools/russia_applicability.py
python -m unittest discover -s tests -v
node tests/ui_smoke.cjs
python tools/watch_pipeline.py validate
git diff --check
python -m http.server 8879 --bind 127.0.0.1
# Открыть http://127.0.0.1:8879/docs/index.html
```

Миграция по умолчанию только показывает план. Для первичного применения нужен
`--write --expect-plan HASH` с хешем предварительного просмотра. При конфликте
с уже структурированной оценкой скрипт останавливается. Валидатор проверяет
соответствие структурированного поля исходной строке и ссылке на её происхождение.
