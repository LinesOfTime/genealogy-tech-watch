# Уточнение назначения четырёх проектов — 22 октября 2026

У Kraken, Tropy, Omeka S и Scriptoria в каталоге сохранялось «Не установлен» в описании назначения, хотя практические сценарии уже были дополнены. Добавлены редакционные пересказы официальных материалов в `editorial_summary`; стандартная миграция выбрала их прежде строки «Назначение:». Исходные выдержки путеводителя не переписывались.

Источники: https://kraken.re/main/index.html ; https://tropy.org/ ; https://omeka.org/s/ ; https://github.com/nikazzio/scriptoria . Проверены заявленные назначения и возможности; программы не запускались и качество на русских источниках не подтверждалось испытанием.

Прежнее описание сохранено в `description_provenance.original_description`, прежнее summary и ссылки на первоисточники — в `editorial_corrections` исследовательской карточки. Новое описание связано с полным текстом summary через SHA-256. Редакционная оговорка о независимой проверке сохранена. Типы проектов, сценарии, ограничения, лицензии, приоритеты, исходные выдержки и история событий не менялись.

Отчёт по всей исходной группе 47 записей обновлён: 46 восстановлены (42 из путеводителя, четыре из новых summary), одна остаётся неопределённой — `linesoftime/yarchive-downloader`. Отсутствие доступного первоисточника не означает отсутствия проекта. Все 17 исходных гипотетических формулировок сохранены. Общий автоматический счётчик provisional теперь равен 19: широкая эвристика также отмечает слова «Возможности» и «возможностей» в двух новых пересказах; это повод прочитать текст, а не доказательство гипотетичности всей карточки.

`tools/enrich_purposes.py` по умолчанию показывает план, применение требует `--write`. Скрипт блокирует замену содержательного описания/summary и конфликтующие повторные правки. Новые тесты проверяют сохранность, идемпотентность и конфликты. Каталог, его копия, встроенные данные и подборка по задачам синхронизированы.

Проверки: 57 тестов unittest прошли; UI smoke прошёл; валидатор — 0 ошибок, 309 предупреждений; повторные `enrich_purposes.py` и `restore_descriptions.py` возвращают пустой список изменений; `git diff --check` без ошибок. Визуальное тестирование браузером в этой серии не выполнялось.

Предыдущий документ DESCRIPTION_FIX_REVIEW.md остаётся историческим отчётом первоначальной миграции (42/5). Текущие результаты по каждой записи находятся в `reports/description-restoration.json` и `.md`. Метод migration-only в этих отчётах описывает восстановление текста, а проверка официальных страниц выполнена отдельным этапом и описана здесь.

GitHub Actions не добавлялись. Эта серия подготовлена локально, публикация не выполнялась.
